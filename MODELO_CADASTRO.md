# 📋 Modelo Prático para Cadastro de Obras e Funcionários (CTRL+C / CTRL+V)
*Use estes modelos para copiar, preencher os dados reais e colar diretamente no formulário de Setup ou me enviar no chat para cadastro em lote.*

---

## 🏗️ 1. Modelo de Cadastro de Obras / Piscinas

Para cada canteiro ou piscina, você só precisa definir estes 5 itens:

### Template Vazio para Preenchimento:
```text
OBRA 1:
Nome Oficial: [NOME EM MAIÚSCULAS, ex: BAHIA]
Local / Cidade: [CIDADE OU BAIRRO, ex: Porto Seguro - BA]
Tipo: [PISCINA ou OBRA CIVIL]
Diária Padrão (R$): [150 para Piscina ou 180 para Civil]
Apelidos do WhatsApp: [apelido 1, apelido 2, apelido 3]
```

### Exemplos Prontos do Campo:
```text
OBRA 1:
Nome Oficial: BAHIA
Local / Cidade: Porto Seguro - BA
Tipo: PISCINA
Diária Padrão (R$): 150

Tipo: OBRA CIVIL
Diária Padrão (R$): 180
Apelidos do WhatsApp: Quase tudo, Loja quase tudo, Obra quase tudo

OBRA 3:
Nome Oficial: CONDOMÍNIO ALPHAVILLE - LOTE 14
Local / Cidade: Alphaville

```

## 👷 2. Modelo de Cadastro de Funcionários

No Ponto Patrícia, apenas o **Nome** e a **Chave PIX** são obrigatórios. Os apelidos garantem que a IA reconheça as mensagens informais enviadas no grupo do WhatsApp.

### Template Vazio para Preenchimento:
```text
FUNCIONÁRIO 1:
Nome Completo: [Nome e Sobrenome]
Chave PIX: [CPF, Celular, E-mail ou Chave Aleatória]
Apelidos do WhatsApp: [como o encarregado escreve no grupo, separados por vírgula]
WhatsApp / Cel: [(opcional) celular com DDD]
Diária Customizada: [(opcional) valor em R$ ou deixar em branco para herdar da obra]
Obra Principal: [(opcional) nome da obra vinculada ou Equipe Volante]
```
